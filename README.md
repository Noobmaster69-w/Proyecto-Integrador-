# Proyecto-Integrador-
# Plataforma Empresarial Distribuida - UIDE

Proyecto Integrador de Tercer Nivel enfocado en el desarrollo de un Chat Empresarial con arquitectura cliente-servidor en Go, integrado sobre una infraestructura de red distribuida (OpenWrt, OSPF, VLANs) y un servicio de autenticación en FastAPI.

## Estructura del Repositorio
- `/docs`: Documentación técnica de las fases, diagramas UML y reportes.
- `/app-go`: Código fuente del cliente y servidor de Chat Empresarial.
- `/auth-service`: Servicio de autenticación desarrollado con FastAPI.
- `/network`: Configuraciones de switches Cisco, routers OpenWrt y topologías.
- `/research`: Instrumentos, datos y análisis para el componente estadístico.

## Declaración de Integridad Académica y Uso de IA
El presente proyecto ha sido planificado y desarrollado por Andrés Guaminga, Bryan Merino y Juan Pindo. Garantizamos que el diseño de la arquitectura, la lógica de programación y las configuraciones de red son de nuestra autoría.

**Uso de herramientas de IA:** Declaramos el uso de Inteligencia Artificial exclusivamente como una herramienta de soporte auxiliar y consulta rápida, respetando las normativas de la UIDE. No se generó código estructural ni documentos completos con IA. Se utilizó únicamente para resolver dudas sintácticas puntuales mediante prompts cortos, por ejemplo: "¿Cuál es la sintaxis recomendada en Go para iterar sobre un mapa de structs concurrentemente?", "Revisa la ortografía de este párrafo" o "como corrijo este error" .
